# AWS Static Website

An entry-level AWS Cloud portfolio project.

## Project Goals

- Host a static website on AWS.
- Secure S3 origin access using CloudFront Origin Access Control.
- Provision infrastructure using Terraform.
- Automate deployment using GitHub Actions and AWS OIDC.
